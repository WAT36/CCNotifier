# CCNotifier - プロダクト概要

## 目的

仮想通貨の定期監視・通知アプリケーション。取引所の販売所レートを定期チェックし、売り時・買い時を自動判定して Slack に通知する。

## 主な機能

- **定期レート監視**: 販売所レートを定期取得し、売り時・買い時を自動判定
- **Slack 通知**: 判定結果を Webhook 経由で Slack に送信
- **資産監視**: DB の記録資産と API 取得の現資産を比較し、差異があればアラート
- **取引履歴管理**: 取引所からエクスポートした CSV を S3 にアップロードし DB に登録
- **BI ダッシュボード**: 通貨毎の利益・取引回数・月次/年次サマリをグラフカード形式で表示

## 対象ユーザー

管理者のみ（セルフサインアップ無効の Cognito 認証）。個人または少人数での仮想通貨取引管理用途。

## データ構造の概要

- **tradeHistory**: 取引履歴メインテーブル（CSV インポート元）
- **brandBidAsk**: 銘柄の買い/売り注文価格管理
- **brandId**: 銘柄名と ID のマッピング
- ビュー多数（`brand_all_profit`, `brand_all_tradecount`, `now_amount`, `now_yen_bet` など）でフロントエンドへの集計を担う
